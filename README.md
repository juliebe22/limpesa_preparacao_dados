# Exercícios de Limpeza e Preparação de Dados

## Sobre o projeto
Atividades acadêmicas da disciplina de Ciência de Dados, do curso de Engenharia de Software, com foco na limpeza e preparação de dados utilizando Python.

## Tecnologias utilizadas
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

## Exercícios

### 1. Valores Ausentes
**Dataset:** Melbourne Housing Snapshot
- Diagnóstico dos dados.
- Identificação e visualização de valores ausentes.
- Comparação entre remoção e imputação.

### 2. Duplicatas
**Dataset:** KPMG Customer Transactions
- Identificação de duplicatas exatas e por subconjunto de colunas.
- Verificação de identificadores únicos.
- Tratamento de duplicatas e análise de impacto nos indicadores.

### 3. Padronização e Escalonamento
**Dataset:** Adult Census Income
- Padronização de dados categóricos.
- Tratamento de valores desconhecidos.
- Aplicação dos métodos Min-Max, Z-score e RobustScaler.
- Comparação dos resultados.

### 4. Outliers
**Dataset:** Diamonds
- Identificação de valores atípicos com Z-score e IQR.
- Visualização com gráficos e boxplots.
- Comparação entre remoção, capping e transformação.

### 5. Pipeline Integrado de Limpeza
**Dataset:** Dirty E-Commerce Data — Shein
- Análise dos dados de Beleza e Saúde e Eletrônicos.
- Conversão de preços e descontos para valores numéricos.
- Tratamento de valores ausentes e duplicatas.
- Padronização de textos.
- Identificação de outliers.
- Criação de novas variáveis.
- Desenvolvimento de uma função reutilizável de limpeza.
- Comparação dos dados antes e depois do tratamento.

## Objetivo
Aplicar técnicas de análise exploratória, limpeza e transformação de dados, compreendendo a importância da qualidade dos dados para análises confiáveis.

## Conclusão
Os exercícios permitem praticar diferentes estratégias de preparação de dados, avaliar seus impactos e desenvolver habilidades fundamentais para projetos de Ciência de Dados.
